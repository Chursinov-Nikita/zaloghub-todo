# Список задач тестовое задание ZalogHub

Работающая версия: https://chursinov-nikita.github.io/zaloghub-todo/

## Запуск

```bash
git clone https://github.com/Chursinov-Nikita/zaloghub-todo.git
cd zaloghub-todo
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173/zaloghub-todo/.

## Скрипты

- `npm run dev` запускает dev-сервер
- `npm run build` проверяет типы и собирает production-версию в dist
- `npm run preview` открывает production-сборку локально
- `npm run lint` проверяет код линтером
- `npm run format` форматирует код через Prettier

## Затраченное время

Примерно 45 мин
